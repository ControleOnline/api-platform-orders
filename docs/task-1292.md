# app-community#1292 — Dashboard collection summaries

Adds explicit `summary=movement` and `summary=paidOrders` to the existing orders collection. Both reuse the authorized collection IDs, company/date filters and parameters. Movement counts all matching order types/statuses by order date, daily/monthly, including an explicit undated count. Paid value sums each order price once for paid/open status; it is not cash received or proof of operational completion. Existing sales and operational summaries are unchanged.

No schema/data migration, new write endpoint or authorization bypass. The implementation extends the published v1.0.6 baseline (including cumulative order access #46) instead of replacing it with the older master contents. Parent task: https://github.com/ControleOnline/app-community/issues/1292.

Focused PHPUnit: dashboard summaries, sales resolver, operational summary — 5 tests / 29 assertions pass; 2 existing PHP 8.5 deprecations.
